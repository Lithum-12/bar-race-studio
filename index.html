说明

改数据
编辑 config/ 里的 JSON。每个条目一个 { name, values }，values 按 time.granularity 的周期依次填数；填 null 表示该周期不在场——开头一段是中途加入，结尾一段是退出。color、icon 可省略，省略时自动配色并生成圆牌徽标。
实时看效果
node tools/serve.mjs 开 localhost:5278，存盘即重读并校验，报错列在画布下方。不想开服务器就 node tools/build.mjs 生成 dist/index.html，双击可跑，配置靠左侧「导入配置」——浏览器不允许本地页面自动读同目录文件。node tools/check.mjs 是无头渲染校验。
导出
逐帧录制，不受窗口大小影响。PNG 序列帧优先写进你选的文件夹，拿不到时打包 zip 并按分辨率限帧。剪辑软件读不准 webm 时长就转封装：ffmpeg -i 输入.webm -c:v libx264 -pix_fmt yuv420p 输出.mp4。
快捷键
空格 播放/暂停 · Home 回开头 · ← → 单步一个周期 · Esc 关闭面板
关于落盘
页面上的调整即时生效但不自动保存——配置文件是唯一真相。要留就点「写回文件」或「下载配置」。
