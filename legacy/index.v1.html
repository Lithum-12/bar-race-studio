使用说明 · 如何替换成自己的数据 / 大事件 / 导出视频

替换数据：用任意文本编辑器打开本文件，在底部找到带醒目注释的 CONFIG / DATA / EVENTS 区块。startMonth 填起始月份（格式 YYYY-MM）；每个条目的 values 按月依次填一个数值，各条目长度保持一致；填 null 表示该月不在榜上——开头一段 null = 该品牌中途加入，结尾一段 null = 中途退出；color 可省略，将按所选配色方案自动配色。

大事件：可在「显示设置 → 大事件」中添加（精确到月），也可以直接编辑代码里的 EVENTS 数组。播放到达该月时，右下角会大字弹出提示，并随视频一起录制。

显示设置：面板中的字体、字号、名称/排名/数值/品牌图标显示位置、条形形状（直角/小圆角/大圆角/胶囊）、背景颜色、配色方案会即时生效并自动保存在本浏览器中。品牌图标支持任意 SVG：在 DATA 条目中加 icon: '<svg ...>...</svg>' 即可，省略则自动生成品牌色徽标。

导出视频：点击「导出视频」后会自动从头录制，动画播放完毕自动生成视频（Chrome / Edge 为 .webm，Safari 可能为 .mp4）。导出为实时录制，导出时长 = 动画时长 ÷ 倍速，录制期间请保持本页面处于前台。个别剪辑软件可能读不准 webm 时长，用 ffmpeg 一条命令转 MP4 即可：ffmpeg -i 输入.webm -c:v libx264 -pix_fmt yuv420p 输出.mp4（仅转封装可加 -c copy）。

操作：空格键 = 播放/暂停；点击或拖动时间轴可跳转到任意月份；时间轴上的刻度为每年 1 月。

当前数据为虚构示例（品牌与数值均为演示用途），仅用于展示效果。
